# BOMBAS-SB

Calendário interativo da disciplina Bombas e Sistemas de Bombeamento - Mackenzie, 2º semestre de 2026.

## Como cadastrar conteúdos

Edite `conteudos.js` e adicione uma entrada usando a data da aula no formato `AAAA-MM-DD`. O próprio calendário transforma a data cadastrada em um bloco clicável com os detalhes da aula.
